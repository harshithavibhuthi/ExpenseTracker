# Expense Tracker

A web app I built to track my daily expenses, visualize spending patterns, and stay on top of my budget.

## What it does

- Add, edit, and delete expenses with category and date
- Dashboard with charts showing spending by category and by date
- Flags unusually high expenses automatically
- Export all your data as a CSV
- Light and dark mode
- Each user has their own account and private data

## Why I built this

I wanted a simple way to track where my money goes every month. 
Most apps are overcomplicated — this one does exactly what I need.

## Built with

- Python + Flask
- PostgreSQL + SQLAlchemy
- Flask-Login for authentication
- Chart.js for the charts
- Vanilla HTML, CSS, JavaScript
